## Overview

ConflictCore is a Project-Based Learning (PBL) project that explores file management and conflict resolution using concepts from Operating Systems and Database Management Systems (DBMS).

The system is designed to manage file operations, coordinate concurrent access, monitor processes, and visualise scheduling and deadlock-related information.

## My Contribution

**Jahnvi Sharma — Frontend UI & Visualisation**

My responsibilities include designing and developing the user interface and visual components for ConflictCore.

Planned frontend features:

- **Dashboard:** Overview of files, processes, locks, and system activity.
- **File Explorer:** Interface for browsing folders and managing files.
- **Process Monitor:** Visual representation of process states and execution information.
- **Scheduling Visualisation:** FCFS, SJF, and Priority scheduling with Gantt charts and performance metrics.
- **Lock Manager:** Display of file locks and waiting processes.
- **Deadlock Visualisation:** Wait-for graph, deadlock alerts, and recovery information.
- **Activity Log:** Display of file operations and their statuses.
- **User Interface:** Clean, minimal, responsive, and easy-to-use design.
